# 方法、根因隔离与下一步

本文将早期工作流规划、数据/渲染排障、BC迭代与安全执行方案收敛为一个可复查的方法。计划中的目标与已经发生的测量分开；个人岗位/面试资料不属于技术发布范围。

## 先把场景定义清楚

UE对象名/组件/Actor标签优先于猜测式识别；融合网格、实例代理、未加载关卡与未知材料不能自动当作已正确物理化。质量、惯量、摩擦、视觉粗糙度分别有不同来源；常见陶瓷杯质量是授权估计，不能伪称称重。静态建筑和动态抓取目标分开，物理材质与视觉材质分开。

## 七项视觉修订

1. 检查倾斜的坏法线常量及贴图解码，强度改变是视觉先验，不是实测微表面参数。
2. 恢复木桌UV平铺；粗糙度mean/std与法线幅度分别检查，不把粗糙度变化压平来做“光滑”。
3. 电磁炉等光滑金属降低过强法线，同时保留金属/粗糙度语义。
4. 原黑玻璃用项目OmniGlass透射路径，核验绑定/MDL，而非仅降低opacity。
5. 落地灯白喷漆和床被亮度问题单列，织物细节保留；不声称精确SSS。
6. 电视按实际材质分段处理；不把整块模型涂白掩盖渲染问题。
7. 红圈/黑轮廓先排重复、退化、法线和渲染模式，不无证据偏移几何。源网格曾审计23714面；该数只属于原场景。

工程实现把意见层先合成，再打开独立渲染进程、attach annotator和预热。禁止在已attach的活stage上切换层栈后直接把坏缓存落盘。相机Rotator统一关键字pitch/yaw/roll，首帧和事后共用位置、前向、上向、HFOV/VFOV门禁。灰卡18%/白卡90%用于隔离照明与曝光；只拟合一个曝光自由度，灰卡±3%、白卡±5%分别验证。ΔE2000按材质区域；SSIM用整幅或规则矩形，不在不规则掩码像素串上算。不同渲染模式不冒充材质改善。

## 原生通道失败先做根因隔离

按相机世界位姿/镜头属性、真实collider净空、语义绑定/filter、annotator构造和时序逐项检查。历史M3的根因是帧0aperture/focal与默认值混用导致FOV崩溃，不能归咎Isaac版本或“渲染器不支持”。保持同一真实机位，只改镜头验证；原生3D框空时重新attach并预热，连续最多10帧空才失败。不得用USD估算框或NOT_APPLICABLE绕过自身bug。

相机净空固定0.15m。live PhysX用overlap_sphere查询真实cooked几何；无live场景时必须提供真实三角面距离检查，不退回整个建筑壳的世界AABB。建筑内部可能落在壳的整体AABB内，不能据此判穿模。

## BC为何用特权状态作基线

早期视觉数据受小杯遮挡、标签大小写/实例ID和原生同步影响，先隔离采集错误，再验证控制。50维状态消除图像渲染通道这一变量，包括杯几何中心、两掌相对杯位姿、手指均值、阶段one-hot、时间与14个手臂关节；不是训练出视觉感知器。

动作以关节范围归一化的相对目标表示，预测8步，每2步再推理。观测时钟为真实50Hz，不用变速phase时钟代替。提取时状态i对应目标i+1起的动作块，越界/跨阶段目标屏蔽。数据集用完整独立轨迹划分训练/验证，重复的确定性轨迹不能充当独立样本；归一化只拟合真实训练集。合成IK样本必须注明来源、经碰撞筛选且不进入验证。新portable trainer不会伪造原实验的875+156行。

旧特权BC在12个初始化可行seed上真实调用241次，0/12；7倾倒、4碰撞、1失衡。旧RMSE约0.03215rad只是动作误差。不能由有限失败断言“再训BC永远无用”或“BC已到理论天花板”。

## 安全执行层的能力与限制

冻结BC目标后加特权几何伺服，之后做关节/速度/倾倒/平衡包络和原生几何过滤。环境使用真实PhysX collider；机器人链节采用保守包围球和离散路径点，存在近似与覆盖盲区，不能保证精确连续全身安全。旧baseline豁免是未归一化点积，单位m²，legacy参数名并不等于精确1mm表面距离。

初始化已倾倒不能靠后续伺服“恢复成成功”；不重置杯、不用运动学固定或附件约束伪造抓取。原始前两步只有接触事件，逐链节球查询覆盖从之后开始，因此历史覆盖为PARTIAL。新链节/新collider接触优先阻断，不能借用掌部旧接触白名单。

## 三类失败分账

布局/初始化不可行、策略执行失败、harness/采集故障分别报告。BC调用为0时不记为策略失败。未运行/缺测=null；实测失败才是false。工作流分母20与初始化放行后的策略分母12不能混用。plan24两轮各0/3，共278次推理、548条动作独立核验；正式批次没跑，成功率null。plan23+24为120+278=398次，而非旧方案误写的561次。

v2改变杯位置后是新分布。包含承托台面的整个杯—橱柜距离要求≥8cm，而杯由该台面支撑时距离约0，故当前布局无法过G0。这揭示契约/支撑布局问题，不能说所有抓杯动作物理上不可能。seed1的第二步/S2未完成保留null；seed11零冲量且正分离的contact-margin报告不夸大为严重穿透。v2未跑BC、未重训、未触发“数据已是唯一瓶颈”的结论。

M2的45次试验仅2次成功且集中于0.5kg：当前固定轨迹对±2mm扰动敏感，主要瓶颈是抓取鲁棒性而非摩擦参数；通用临界摩擦不能从该非单调网格识别，保留null。

## 专家视频与下一步

专家使用厂商腿部策略、已有高层导航及IK/接触控制，在名义v1场景完成拿杯→右转→身体前向行走→左转面对电脑桌→放杯。先保存真实物理和审计，再用cam01路径原生渲染；重放阶段关闭物理并明确2.3488×时间压缩。专家成片不能并入BC成功率。

后续研究顺序：重新定义可行支撑/障碍契约并预注册 → 多起点独立成功/恢复演示 → 重新训练和固定20seed评测 → 必要时BC热启动PPO，设计观测、动作、奖励、失败/重置规则和安全边界。PPO尚未实现/验收；不保证提高成功率。新场景和新契约单列版本，旧失败结论不回写。
