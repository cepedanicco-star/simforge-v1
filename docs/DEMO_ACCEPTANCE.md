# 每段的可展示产物与量化门禁

下表是使用者在本机复现时应产出的文件；本源码包不携带许可资产、原始帧、逐拍日志或历史JSON。历史成绩只见results摘要，不能把未重跑的条目写成新验收通过。

| 阶段 | 可拍摄/查看的产物 | 量化门禁 |
|---|---|---|
| 资产无关快检 | 终端4项PASS与自有合成USD装配过程 | 4/4，源哈希不变、6seed一致；不是原生M1–M4 |
| UE→USD→Isaac | 编辑器导出与Isaac打开新意见层 | 源层哈希变化0；未知参数显式标记，不伪称标定 |
| 材质/灰卡 | 6帧配对、前后对照与材质表 | 6/6相机门禁；位置≤1e-6m，方向/FOV≤1e-4°；灰±3%、白±5%分别记账 |
| M1 | 框叠加demo、RGB/深度/分割预览 | 20/20完整帧；2D框偏差≤5px、主点≤2px，原生3D框非空 |
| M2 | 成败对照与3×3热图 | 45/45记录；抬升≥50mm、滑移≤5mm、保持≥2s；同seed精确复现 |

| BC训练 | loss.csv曲线与独立验证误差 | 轨迹交集0；真实训练集归一化；损失降≥10%且plateau达到120轮才标收敛 |
| 闭环/安全执行 | 每seed动作回放与调用/失败摘要 | 预注册20seed；条件成功数/初始化放行数与工作流成功数/20分别报告；0调用保持null |
